# Та-ти-ти

Маленькая ритм-игрушка, чтобы научиться читать ритм по слогам Кодая — та, ти-ти, там-ти. Послушай строчку, простучи её сам или собери свою.

**Открыть:** https://mopheadpersona.github.io/kodaly/ (в шапке переключи на RU)

[English version](README.md)

## Что умеет

- **Слушать** — такт счёта, потом метроном и тон на каждую ноту, текущий слог крупно.
- **Стучать** — только метроном. Стучи по площадке, пробелом или Enter. Нота становится зелёной (в точку, до 70 мс), жёлтой (почти, до 150 мс) или красной (мимо).
- **Без конца** — новые ритмы идут без остановки, следующая строчка видна заранее.
- **Собери свой** — кусочки встают в такты по порядку; потом слушай, стучи или крути по кругу.
- 2/4, 3/4 и 4/4; три уровня (без ти-ти / с ти-ти / с там-ти); английский и русский; светлая и тёмная тема.

На айфоне выключи беззвучный режим: он глушит звук в браузере.

## Поставить на экран «Домой»

Открой ссылку в Safari → «Поделиться» → **«На экран „Домой“»**. После этого приложение открывается как отдельное, без адресной строки, и работает без сети — в метро, в авиарежиме. Обновления приходят сами: после изменения новая версия появится при следующем запуске.

## Запустить у себя

```bash
python3 scripts/serve.py
```

Потом открыть http://localhost:8000. Это обычный `http.server` из Python, только без кэша: правки видны после перезагрузки. Двойной щелчок по `index.html` не сработает: браузер не грузит ES-модули с `file://`. Офлайн-кэш на localhost выключен; чтобы попробовать его, добавь к адресу `?sw`.

## Как устроено

Статический сайт: HTML, CSS и ES-модули. Без фреймворка, без сборки, без зависимостей. Состав файлов — в [README.md](README.md). Каждый push в `main` GitHub Pages выкладывает сам.

Тесты: `npm test` — встроенный в Node запуск тестов, ставить ничего не нужно. Проверяют генератор ритмов, оценку ударов, тексты на обоих языках и офлайн-кэш.

После изменения любого файла, который грузит приложение, нужно запустить `npm run stamp`: так у офлайн-кэша появится новая версия, и телефоны подхватят изменения. Пока это не сделано, тесты падают.
