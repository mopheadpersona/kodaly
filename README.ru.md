# Та-ти-ти

Маленькая ритм-игрушка, чтобы научиться читать ритм по слогам Кодая — та, ти-ти, там-ти. Послушай строчку, простучи её сам или собери свою.

**Открыть:** https://mopheadpersona.github.io/kodaly/ (в шапке переключи на RU)

[English version](README.md)

## Что умеет

- **Слушать** — такт счёта, потом метроном и тон на каждую ноту, текущий слог крупно.
- **Стучать** — только метроном. Стучи по площадке, пробелом или Enter. Нота становится зелёной (в точку, до 70 мс), жёлтой (почти, до 150 мс) или красной (мимо).
- **Без конца** — новые ритмы идут без остановки, следующая строчка видна заранее.
- **Собери свой** — кусочки встают в такты по порядку; потом слушай, стучи или крути по кругу.
- 2/4, 3/4 и 4/4; три уровня (без ти-ти / с ти-ти / с там-ти); английский и русский; светлая и тёмная тема.

На айфоне выключи беззвучный режим: он глушит звук в браузере.

## Запустить у себя

```bash
python3 -m http.server 8000
```

Потом открыть http://localhost:8000. Двойной щелчок по `index.html` не сработает: браузер не грузит ES-модули с `file://`.

## Как устроено

Статический сайт: HTML, CSS и ES-модули. Без фреймворка, без сборки, без зависимостей. Состав файлов — в [README.md](README.md). Каждый push в `main` GitHub Pages выкладывает сам.

Тесты: `npm test` — встроенный в Node запуск тестов, ставить ничего не нужно. Проверяют генератор ритмов, оценку ударов и тексты на обоих языках.

## Основа

Порядок ритмов — по главе 1 книги Ottman & Rogers, *Music for Sight Singing* (доля и её деление пополам). Ритмы приложение генерирует само, из книги ничего не скопировано.
